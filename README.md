# Konto Planer

Zeigt für jedes Girokonto, wie viel Geld bis zum nächsten Gehaltseingang mindestens drauf sein muss – und wie viel davon frei verfügbar ist.

Selbst gehostete Web-App (SvelteKit, PostgreSQL) als Docker-Stack fürs Heimnetz. Status: in Entwicklung, siehe [docs/PLAN.md](docs/PLAN.md).
